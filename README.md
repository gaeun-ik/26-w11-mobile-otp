# OTP LAB — 모바일 OTP 체험 스튜디오 (RFC 6238) (`26-w11-mobile-otp`)

> 스마트폰의 Google Authenticator, Microsoft Authenticator와 인터넷 없이도 30초마다 똑같은 6자리 번호를 계산해내는 현대적인 모바일 OTP(TOTP) 보안 대시보드 웹앱입니다.

---

## 🌟 프로젝트 소개 (OTP LAB)

**OTP LAB**은 RFC 6238(TOTP) 및 RFC 4226(HOTP) 표준 규격을 준수하는 모바일 OTP 체험 및 양방향 검증 웹앱입니다.
다크 사이버보안 대시보드 테마로 제작되었으며, 스마트폰 Authenticator 앱으로 QR 코드를 스캔하여 등록하고, 30초마다 동기화되는 6자리 인증번호의 실시간 일치 여부를 즉각 검증할 수 있습니다.

- **안전한 비밀 키 발급**: `window.crypto.getRandomValues` 기반 160비트(20바이트) 암호학적 난수(CSPRNG) 생성
- **스마트폰 QR 연동**: `otpauth://totp/...` 표준 포맷 QR 코드를 스마트폰 Authenticator 앱으로 스캔 등록
- **실시간 정밀 모니터**: `Date.now()` 밀리초 기반 정밀 30초 카운트다운 게이지 및 실시간 6자리 코드 표시
- **양방향 인터랙티브 검증기**: 스마트폰에 표시된 번호를 직접 입력해 즉각적인 일치/불일치 판정 (±30초 시간 오차 보정 옵션 포함)
- **Zero-Transmission 보안 보증**: 외부 서버 통신 0건, 브라우저 내장 Web Crypto API(`crypto.subtle`) 100% 로컬 연산

3. **구현 중 문제 해결 (Troubleshooting)**:
   - **RFC 6238 표준 벡터 일치**: 브라우저 환경에서 64비트 정수 카운터를 8바이트 Big-Endian 버퍼(`DataView.setBigUint64`)로 정확히 변환하고, HMAC-SHA1 서명 후 하위 4비트 오프셋 기반 동적 절단(Dynamic Truncation)을 엄격히 구현하여 RFC 6238 공식 테스트 벡터(Time: 59s, 1111111109s, 1234567890s 등)를 100% 통과(`test-totp.js`)했습니다.
   - **타이머 오차(Drift) 방지**: 단순 `setInterval`의 지연 누적 문제를 해결하기 위해 `Date.now()`의 실제 밀리초를 역산하여 매 100ms마다 정확한 남은 초와 원형 게이지 둘레(`stroke-dashoffset`)를 부드럽게 갱신하도록 설계했습니다.
   - **시간 오차(Time-drift) 대응**: PC와 스마트폰 간의 미세한 시간 차이(1~2초 오차로 30초 경계선에서 번호가 엇갈리는 현상)를 방지하기 위해 Window ±1 스텝(앞뒤 30초) 시간 보정 옵션을 기본 탑재했습니다.

## 🛡️ TOTP 원리 및 보안 점검 (사이버보안과 체크포인트)

1. **비밀 키 생성 시 `Math.random()` 대신 `crypto.getRandomValues()`를 사용해야 하는 이유**:
   - `Math.random()`은 의사 난수 생성기(PRNG)로, 내부 시드 상태를 역추적하면 다음에 생성될 키를 공격자가 수학적으로 완벽히 예측할 수 있습니다.
   - 반면 `window.crypto.getRandomValues()`는 암호학적으로 안전한 의사 난수 생성기(CSPRNG)로, 운영체제 커널의 하드웨어 엔트로피(마우스 움직임, CPU 인터럽트, 키보드 타이밍 등)를 활용하므로 다음 난수를 예측하는 것이 사실상 불가능합니다.

2. **외부 서버 전송 없는 클라이언트 연산(Zero-Transmission)의 보안적 이점**:
   - 비밀 키 생성, HMAC-SHA1 연산, OTP 검증이 100% 브라우저 메모리 안(`crypto.subtle`)에서만 수행됩니다.
   - 네트워크를 통해 비밀 키나 OTP 번호가 패킷 형태로 전송되지 않으므로, 패킷 스니핑, 중간자 공격(MITM), 백엔드 서버 침해에 따른 비밀 키 유출 위협을 근본적으로 차단할 수 있습니다.
   - **실제 Network 탭 확인 결과**: F12 개발자 도구의 Network 탭에서 키 생성 및 OTP 검증 수행 시 외부 HTTP/WebSocket 트래픽이 일절 발생하지 않음(0건)을 확인하였습니다.

3. **스마트폰 Authenticator 앱과의 일치 확인**:
   - Google Authenticator 앱으로 웹 화면의 QR 코드를 스캔하여 계정을 등록한 결과, 스마트폰 화면의 6자리 인증번호와 웹 대시보드의 실시간 OTP 번호가 30초마다 동시에 정확히 일치함을 확인하였습니다.

## ✨ 나만의 확장 기능 (Security & UX Enhancements)

1. **실시간 SVG 원형 카운트다운 게이지**:
   - 밀리초 단위 부드러운 원형 게이지 애니메이션 제공
   - 남은 시간이 5초 이하로 줄어들면 붉은색 네온 경고 펄스로 즉시 전환되어 만료 임박을 직관적으로 안내
2. **발급자(Issuer) 및 계정명(Account) 커스텀 설정**:
   - 사용자가 원하는 서비스 이름(예: `Naver`, `GitHub`, `Kopo OTP`)과 이메일 계정을 자유롭게 변경하여 QR 코드 생성 가능
3. **원클릭 클립보드 복사 & 키 마스킹 토글**:
   - 160비트 Base32 비밀 키를 눈 아이콘으로 안전하게 숨기거나 확인할 수 있으며, 4자리 단위 가독성 공백 포맷 지원
4. **유연한 시간 오차(±30초 Window) 보정 토글**:
   - 엄격 모드(현재 30초만 인정)와 유연 모드(앞뒤 30초 인정)를 토글하여 실제 인증 시스템과 동일한 환경 체험 지원
5. **최근 검증 이력 히스토리 로그**:
   - 최근 5건의 인증 시도(시각, 입력 코드, 일치/불일치, 시간 델타)를 실시간 피드백 카드로 기록
6. **사이버보안 원칙 & 안전성 진단 인터랙티브 탭**:
   - CSPRNG, Zero-Transmission, RFC 6238 3요소 원리를 직관적인 카드와 체크포인트로 시각화
